# Campus map and school directory

Open **Horario**, then **Mapa universitario**. The directory can filter by
physical campus and search by school, faculty, or an academic program name.
A selected school displays its published address and highlights the building
when OpenStreetMap identifies it by name. Schools with a confirmed campus
and no reliable building coordinate use the campus marker. Agronomy displays
the published Urbanización Aurora address beside the stadium.

The directory data ships with the app. Its filters and addresses work without
a session or a network connection once the application shell is available.
Leaflet loads the OpenStreetMap basemap only when the screen is open and
online. The baseline view has public campus markers and visible attribution.
